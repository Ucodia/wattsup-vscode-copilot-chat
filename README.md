# Wattsup with Github Copilot

*This is a fork of [vscode-copilot-chat](https://github.com/microsoft/vscode-copilot-chat), the official VS Code extension for Github Copilot Chat.*

Wattsup with Github Copilot allows you to monitor AI requests usage with the integrated Wattsup dashboard, giving quick access to key metrics such as output token usage and carbon emissions over different time periods.
